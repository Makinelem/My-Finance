GESTÃO PESSOAL — primeira versão móvel

1. Extraia os arquivos.
2. Abra index.html no navegador para testar.
3. No primeiro acesso, crie um PIN de 4 a 6 números.
4. Os dados ficam no armazenamento local do navegador.

Observação: esta primeira versão é um protótipo funcional offline. O PIN protege a interface no navegador, mas não substitui uma autenticação com servidor para segurança forte ou sincronização entre dispositivos.
